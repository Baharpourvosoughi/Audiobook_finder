# Multi-Source Audiobook Finder CLI 🎧📚

A Python command-line utility that scrapes and searches for free audiobooks across multiple audiobook repositories simultaneously using `BeautifulSoup` and `requests`.

## Features

- Multi-source aggregated search across 4 public platforms.
- Resilient scraping with custom User-Agent and timeout handling.
- Interactive CLI with direct browser opening.

## How to Run

1. Install dependencies:
```bash
   pip install -r requirements.txt
```
2. Run the application
```bash
   python main.py
```
